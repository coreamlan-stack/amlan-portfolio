# Amlan Kumar Bhowmik — Portfolio

Personal portfolio for Amlan Kumar Bhowmik, a Software Developer and UI/UX Designer. The site focuses on thoughtful interfaces, responsive implementation, and accessible motion.

## Stack

- Next.js 14 and React 18
- Tailwind CSS and styled-components
- Framer Motion, GSAP, and Lenis

## Development

```bash
npm install
npm run dev
```

Run quality checks with `npm run lint` and make a production build with `npm run build`.

## Content policy

Work cards are intentionally marked as placeholders until project details, responsibilities, and approved visuals are ready to publish. The portfolio does not include invented clients, testimonials, employment claims, or social profiles.
