# Core Amlan - Portfolio

Personal portfolio for Core Amlan, a Software Developer and UI/UX Designer. The site focuses on thoughtful interfaces, responsive implementation, and accessible motion.

## Stack

- Next.js 14 and React 18
- Tailwind CSS and styled-components
- Framer Motion, GSAP, and Lenis

## Development

```bash
npm install
npm run dev
```

Run quality checks with `npm run lint` and make a production build with `npm run build`.

## Content policy

Project cards use authentic supplied screens. The portfolio does not include invented clients, testimonials, employment claims, or social profiles.
